Política de Privacidad

Última actualización: 12 de octubre de 2026.

Esta política explica cómo trata la información El Camino Dental, un juego educativo disponible como sitio web y aplicación Android, desarrollado por Mtra. Yomira Salgado Martinez.

Resumen: no se necesita una cuenta; el juego no integra publicidad ni analítica propia; el progreso y las actividades se guardan localmente; y el multijugador Android utiliza Bluetooth para la comunicación entre dispositivos.

1. Información que puede utilizar el juego

Según las funciones utilizadas, el usuario puede introducir nombres o apodos, crear preguntas, respuestas, actividades y casos educativos, y guardar el progreso de una partida. También se conserva información necesaria para el funcionamiento de la sesión, como personajes seleccionados, posición de las fichas, preguntas utilizadas y estado de una sala Bluetooth.

Estos datos se guardan localmente en el navegador o dispositivo. El proyecto no dispone de una cuenta de usuario ni de una base de datos propia que reciba los datos de las partidas.

2. Permisos de Bluetooth en Android

El multijugador puede solicitar permisos de Bluetooth para buscar dispositivos cercanos, anunciar la disponibilidad del dispositivo y establecer o mantener una conexión entre jugadores. Bluetooth se utiliza para la comunicación local entre los dispositivos participantes. El juego no solicita ubicación precisa como función propia; Android puede mostrar avisos o aplicar requisitos según la versión instalada.

Si no se conceden los permisos, las funciones multijugador que dependan de Bluetooth pueden no estar disponibles. Los permisos se pueden administrar o revocar desde los ajustes de Android.

3. Información que no solicitamos deliberadamente

El juego no requiere nombre legal, domicilio, correo electrónico, teléfono, fecha de nacimiento, información financiera ni credenciales de otras cuentas. No integra acceso propio a contactos, cámara, micrófono o galería para las funciones descritas en esta política.

No introduzcas contraseñas, expedientes clínicos identificables, datos sensibles de pacientes ni información personal innecesaria en nombres, actividades, preguntas o casos.

4. Almacenamiento local, importación y exportación

El progreso, los nombres o apodos y el contenido creado en el Modo Docente pueden guardarse localmente. Las funciones de exportación generan archivos en el dispositivo; la importación procesa el archivo que el usuario selecciona. El proyecto no recibe automáticamente esos archivos.

El usuario puede borrar el progreso desde las opciones disponibles en el juego o eliminar los datos de la aplicación o del sitio desde los ajustes del dispositivo o navegador. Al borrar el almacenamiento, desinstalar la aplicación o cambiar de dispositivo, los datos locales pueden perderse. Si el usuario comparte manualmente un archivo exportado, su tratamiento posterior dependerá de la aplicación o persona receptora.

5. Alojamiento web y distribución Android

La versión web se aloja en GitHub Pages. GitHub puede procesar información técnica de las visitas, como direcciones IP y registros de solicitudes, para operar y proteger su servicio. Consulta la Declaración General de Privacidad de GitHub.

La aplicación Android se distribuye o prepara para distribución mediante plataformas de terceros, como Google Play. Estas plataformas pueden tratar información técnica de descarga, instalación, seguridad o funcionamiento conforme a sus propias políticas. Esta política describe el comportamiento del proyecto y no sustituye las políticas de los proveedores externos.

6. Cookies y tecnologías similares

El código propio del juego utiliza almacenamiento local para conservar el estado de la partida y las actividades. No incorpora cookies publicitarias ni herramientas propias de seguimiento publicitario o analítica. El proveedor de alojamiento puede utilizar tecnologías necesarias para la seguridad y operación de su infraestructura conforme a sus políticas.

7. Menores de edad y uso educativo

El juego tiene finalidad educativa y puede utilizarse en contextos académicos. No está diseñado para recopilar deliberadamente datos personales de menores. Se recomienda utilizar apodos, nombres de pila o números de equipo y evitar información sensible, con la supervisión que corresponda al contexto educativo.

8. Información clínica

Las preguntas y los casos tienen finalidad docente. El juego no está diseñado para almacenar expedientes clínicos reales. No introduzcas datos que permitan identificar pacientes. El contenido educativo no sustituye la evaluación, el diagnóstico ni el tratamiento profesional.

9. Seguridad y conservación

La arquitectura intenta reducir la recopilación mediante almacenamiento local y comunicación Bluetooth entre dispositivos. Ningún sistema puede garantizar seguridad absoluta. La información local se conserva hasta que el usuario o el sistema la elimina o se sobrescribe durante el uso. No podemos eliminar a distancia datos guardados únicamente en el dispositivo del usuario.

10. Enlaces y servicios de terceros

El sitio puede incluir enlaces externos. Al abrirlos, se aplican las políticas del sitio de destino. No controlamos las prácticas de privacidad de GitHub, Google Play ni otros proveedores externos.

11. Cambios en esta política

Esta política se actualizará si cambian las funciones, los permisos, los servicios externos o las prácticas de tratamiento de información. La fecha de actualización aparece al inicio.

12. Contacto

Para reportar cuestiones de privacidad o funcionamiento, utiliza la sección de incidencias del proyecto en GitHub.
